# Product Backlog

This backlog contains all the epics and user stories for the AI-HMS project, prioritized by milestone.

## Milestone 1: Authentication & User Management

### 1. Initialize Codebase
* **Priority:** High
* **Status:** In Progress
* **Story Points:** 3
* **User Story:** As a developer, I want to initialize the React and Django projects so that development can begin.

### 2. User Registration
* **Priority:** High
* **Status:** To Do
* **Story Points:** 5
* **User Story:** As a user, I want to register a new account so that I can access the system.

### 3. Secure Login (JWT)
* **Priority:** High
* **Status:** To Do
* **Story Points:** 5
* **User Story:** As a user, I want to securely log in with an email and password using JWT so my data is protected.

### 4. Role-Based Route Protection
* **Priority:** High
* **Status:** To Do
* **Story Points:** 5
* **User Story:** As the system, I want to restrict route access based on the user's role (Admin/Doctor/Patient/Receptionist) so that data remains secure.
